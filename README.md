# 🎮 AI Tic-Tac-Toe with Minimax & Alpha-Beta Pruning

An intelligent Tic-Tac-Toe game built using **React.js** featuring an unbeatable AI opponent powered by the **Minimax Algorithm** and optimized using **Alpha-Beta Pruning**.


## 📌 Features

* Human vs AI gameplay
* Unbeatable AI opponent
* Minimax Algorithm implementation
* Alpha-Beta Pruning optimization
* Interactive React UI
* Real-time game status updates
* Restart game functionality
* Responsive design

---

## 🧠 AI Strategy

The AI uses the **Minimax Algorithm**, a decision-making algorithm commonly used in game theory and artificial intelligence.

### Minimax

The algorithm explores all possible future game states and selects the move that maximizes the AI's chances of winning while minimizing the opponent's chances.

### Alpha-Beta Pruning

Alpha-Beta Pruning improves Minimax performance by eliminating branches that cannot influence the final decision.

Benefits:

* Faster search
* Reduced computation
* Same optimal result as standard Minimax
